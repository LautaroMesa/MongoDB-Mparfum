Guion: backup y restauración de la base

Proyecto Mparfum · Diseño de Bases de Datos II · Universidad de Mendoza · 2026
Para cuando el profesor pida: "mostrame cómo se hace un backup de tu base de datos". Duración: unos 3 minutos.

Antes de la exposición

  • Tener dos ventanas abiertas: el CMD con mongosh y MongoDB Compass.
  • Abrir mongosh desde la carpeta del proyecto, para que load("backup/...") encuentre los archivos:
cd "C:\Users\Lautaro Mesa\OneDrive\Desktop\Base de Datos II\BD 2 PROYECTO\BD 2 PROYECTO"
mongosh
  • Dentro de mongosh, dejar seleccionada la base:
use mparfum
  • Si es posible, tener instaladas las MongoDB Database Tools (traen mongodump y mongorestore), para poder mostrar la opción A.
  • La consola de Compass no sirve para esto: no permite load() ni require(). Usar siempre el mongosh del CMD.

Guion paso a paso

1. Explicar la política (30 segundos, sin comandos)

Nuestra política es un backup completo diario a las 3 de la mañana, que es la hora de menos tráfico de la tienda. Guardamos los últimos 7 diarios, 4 semanales y 12 mensuales. Una vez por semana restauramos el último backup en una base aparte para comprobar que funciona.

2. Mostrar cuántos datos hay

db.pedidos.countDocuments()

Tenemos 20.000 pedidos.

3. Hacer el backup

Opción A: con la herramienta oficial, mongodump (requiere las Database Tools)

const { execSync } = require("child_process")
execSync('mongodump --db=mparfum --gzip --archive=mparfum_backup.archive.gz', { stdio: "inherit" })

mongodump guarda la base en formato BSON comprimido: los datos, los índices y los validadores.

Opción B: con el script del proyecto (no requiere nada extra)

load("backup/backup_mongosh.js")

Este script guarda cada colección con sus documentos, sus índices, el validador y las vistas, comprimido en una carpeta con la fecha.

Si hay tiempo, mostrar el archivo o la carpeta del backup en el Explorador de Windows (carpeta resguardos).

4. Simular un desastre

db.pedidos.deleteMany({ canal: "app" })
db.pedidos.countDocuments()

Un empleado borró por error todos los pedidos de la app. Perdimos unos 5.500.

Recargar Compass (botón 🔄) para que se vea que bajó la cantidad de pedidos.

5. Restaurar

Opción A: mongorestore

execSync('mongorestore --gzip --archive=mparfum_backup.archive.gz --nsInclude=mparfum.* --drop', { stdio: "inherit" })

Opción B: script del proyecto

var DESTINO = "mparfum"
load("backup/restaurar_mongosh.js")

Si se cerró mongosh entre el backup y la restauración, antes del load indicar la carpeta del backup (con barras /):
var CARPETA = "C:/Users/Lautaro Mesa/OneDrive/Desktop/Base de Datos II/BD 2 PROYECTO/BD 2 PROYECTO/resguardos/mparfum_AAAA-MM-DD_HHMM"

6. Comprobar

db.pedidos.countDocuments()

Volvimos a los 20.000 pedidos.

Recargar Compass: se ve que los pedidos volvieron.

Extra: verificar un backup sin tocar la base original

var DESTINO = "mparfum_restore"
load("backup/restaurar_mongosh.js")
load("backup/verificar_restore.js")

Tiene que terminar con "RESGUARDO VERIFICADO". La base mparfum_restore aparece en Compass. Para borrarla: db.getSiblingDB("mparfum_restore").dropDatabase()

Preguntas que te pueden hacer

PreguntaRespuesta
¿Qué diferencia hay entre mongodump y mongoexport?mongodump guarda en BSON con los tipos exactos, más los índices y los validadores: sirve para recuperar la base. mongoexport saca JSON o CSV, sólo datos: sirve para compartir.
¿Qué es el RPO y el RTO?RPO: cuántos datos se pueden perder como máximo; con backup diario, hasta 24 horas. RTO: cuánto tarda la base en volver a funcionar; en nuestro caso, segundos.
¿Y si se rompe el disco?Por eso aplicamos la regla 3-2-1: 3 copias, en 2 medios distintos y 1 fuera del servidor. Un backup en el mismo disco no sirve si se rompe el disco.
¿Cómo sabés que el backup sirve?Lo restauramos en otra base (mparfum_restore) y lo comparamos colección por colección con verificar_restore.js: documentos, índices y validadores.
¿Qué pasa con los pedidos que entran durante el backup?Con un replica set se usa --oplog, y el backup queda consistente a un único instante.
¿Por qué no usar "Exportar" de Compass?Porque exporta sólo los datos, en JSON o CSV: no guarda índices ni validadores, y en CSV se pierden los tipos.
¿Cómo se protegen los datos personales del backup?Por la Ley 25.326: acceso restringido a la carpeta de backups, cifrado de la copia que sale del servidor y retención limitada (7 / 4 / 12).
